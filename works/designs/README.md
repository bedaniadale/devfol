# Graphic design assets

Place your graphic design images here (PNG, JPG, or WebP).

In `designs.js` at the portfolio root, update each entry’s `img` field to point to files in this folder, for example:

```js
img: 'works/designs/my-poster.png',
```

You can also adjust `title`, `desc`, `category` (`poster`, `social-media`, or `branding`), and `tools` for each piece.
